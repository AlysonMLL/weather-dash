Arquitetura & Como Funciona

Visão geral do pipeline de dados e otimizações aplicadas neste dashboard.

Micro-ETL & Cache (SQLite)

Para evitar chamadas redundantes à API externa (OpenWeatherMap), o backend atua como um orquestrador. Os dados são extraídos, transformados (padronização de JSON) e carregados em um banco SQLite. Requisições subsequentes dentro de 15 minutos são servidas instantaneamente via cache local.

Busca com Debounce

A barra de pesquisa consome a API de Geocoding. Para proteger a cota de requisições do servidor, foi implementada uma função de Debounce no JavaScript, que retém as chamadas e só processa a busca 500ms após o usuário parar de digitar.

Estado e Data Viz

As cidades escolhidas são salvas no LocalStorage, garantindo persistência de estado sem necessidade de login. A visualização de dados (Data Viz) é renderizada dinamicamente com Chart.js, reagindo automaticamente à mudança de tema Claro/Escuro do sistema.
